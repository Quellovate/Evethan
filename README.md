# Evethan (伊芙森) - 集成脚本系统

Evethan 是一款基于 Python 和 PySide6 构建的桌面自动化工具，提供可视化的无代码脚本编辑器。

## 1. 运行要求

- **操作系统**：Windows 10/11（仅限 64 位）。暂不支持 Windows 7/8、macOS 及 Linux。
- **运行权限**：**必须以“管理员身份”运行**（涉及全局快捷键与底层驱动通信）。
  - *EXE 运行*：双击后在 UAC 提示中选“是”。
  - *源码运行*：需确保 IDE（如 VSCode）或终端以管理员身份运行。
- **Python 版本**：强烈建议使用 **Python 3.10 (64位)**。
- **硬件建议**：建议配备独立显卡（NVIDIA / AMD），以保障 `dxcam` 极低延迟的屏幕抓取效能。

## 2. 安装与启动

**安装依赖库：**
```bash
pip install PySide6 opencv-python numpy pyautogui dxcam keyboard
```

**启动程序：**
```bash
python main.py
```
> **提示**：Release 页面已提供打包好的安装包，可直接下载使用。

## 3. 注意事项与常见问题 (FAQ)

- **关于罗技硬件驱动模拟**：
  本项目提供“Windows 软件模拟”与“罗技硬件模拟”两种模式。开启硬件模拟**无需实体罗技鼠标**，只需安装 Logitech G HUB（建议版本：`2021.11.1775` 或更早版本）即可生效。
- **杀毒软件误报 `lgdrivr.pyd`**：
  该文件为罗技驱动通信接口（基于 **Python 3.10 64位** 编译，通常仅能在**同版本**下运行）,如遇杀毒软件拦截，直接删除该文件即可，系统会自动回退至 `PyAutoGUI` 软件模拟模式，不影响核心功能。
- **双显卡笔记本（核显+独显）找图失效/黑屏解决办法**：
  因抓取 API 与游戏渲染不在同一 GPU 上导致。请前往 `Windows 设置 -> 系统 -> 屏幕 -> 显卡/显示卡 -> 添加桌面应用`，找到本程序 `Evethan.exe`（或相关 Python 解释器），将其 GPU 首选项手动设置为 **“高性能（你的独立显卡）”**。

## 4. 项目结构

- **前端 UI**
  - `main.py`：主程序入口（主窗口、任务编辑器/执行器/管理器、全局快捷键）。
  - `ui_components.py`：核心组件（工具箱、属性/批量/说明编辑器等）。
  - `ui_system.py`：系统设置页面（OSD 悬浮日志与配置、默认参数设置）。
  - `ui_styles.py`：UI 样式管理（颜色、字体、尺寸、QSS 样式表）。
  - `tools.py`：屏幕辅助工具（定位、测距、截图、按键录制）。
- **后端逻辑**
  - `driver.py`：底层硬件/软件键鼠操作驱动及 OpenCV 图像识别。
  - `executor.py`：脚本执行器（封装鼠标、键盘、找图等自动化指令）。
  - `scheduler.py`：脚本调度器（解析并按序执行指令，处理循环、分支等控制流）。
  - `config.py`：配置管理器与工程文件 (.json) 读写。
  - `utils.py`：通用工具箱（图像处理、鼠标轨迹、按键解析等）。
  - `definitions.py`：全局静态定义（默认设置、动作工厂、参数翻译）。
